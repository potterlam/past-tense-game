# 英語過去式發音冒險遊戲 (English Past Tense Pronunciation Adventure Game)

一款教育性的網頁遊戲，旨在幫助學習者掌握英語過去式的發音規律 (/t/, /d/, /ɪd/)。

## 遊戲特色

- 🎮 互動式學習體驗
- 🎵 豐富的音效和背景音樂
- 🎬 故事模式和過場動畫
- 🏆 多階段闖關系統
- 📚 單詞搜尋和選擇題模式
- 👑 最終 Boss 戰

## 文件結構

```
├── index.html          # 主遊戲頁面
├── css/
│   └── style.css       # 遊戲樣式
├── js/
│   └── script.js       # 遊戲邏輯
├── assets/
│   ├── images/         # 遊戲圖片資源
│   ├── audio/          # 音效文件
│   │   ├── bgm.mp3

```

## 如何運行

1. 克隆此存儲庫：

2. 確保所有資源文件都在正確的位置

## 遊戲內容

### 學習目標
- 掌握英語過去式三種發音：/t/, /d/, /ɪd/
- 通過遊戲化學習提高記憶效果
- 培養語音意識和發音準確性

### 遊戏階段
1. **教學關卡** - 學習基本發音規則
2. **練習關卡** - 單詞搜尋和選擇題
3. **挑戰關卡** - 面對不同難度的敵人
4. **最終戰** - 發音之王挑戰
